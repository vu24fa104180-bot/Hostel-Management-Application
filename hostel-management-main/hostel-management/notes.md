main folder has 2 folders: frontend and backend
backend folders:
1. controllers: contains buisiness logic.
2. routes: which controller or function to execute when a specific url is requested by user.
**imp** : http requests are stateless. 
3. middleware: middleware is a function that runs between request and response
4. models: (each file in models folder represents a table in database). model contains mongoose schema using which, backend can easily interact and work with database.
5. node_modules: it contains all important libraries annd files of node.js
