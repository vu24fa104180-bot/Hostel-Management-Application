# Hostel Management System

A full-stack web application that simplifies hostel management by allowing students to book rooms online and raise maintenance complaints, while enabling administrators to manage room allocations and resolve complaints efficiently.

## Live Demo

* Frontend: https://dazzling-scone-e3f1cc.netlify.app
* Backend API: https://hostel-management-system-oo39.onrender.com

## Features

* Student Registration & Login
* Room Booking System
* Complaint Management
* Admin Dashboard
* Room Management
* JWT Authentication

## Tech Stack

**Frontend:** React.js, Vite, Axios, CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB Atlas

**Deployment:** Netlify, Render

## Project Structure

```text
hostel-management/

```
